# Indigo Tree Consulting Website

A professional, clean website for Indigo Tree Consulting — an Indianapolis-based tree consulting firm.

## Site Structure

```
indigo-tree-site/
├── index.html          # Homepage with hero, services preview, about preview, CTA
├── services.html       # Detailed service pages (risk assessment, appraisal, inventory)
├── about.html          # About Andrew Mertz, timeline, certifications
├── contact.html        # Contact form, info, FAQ, map
├── css/
│   └── style.css       # Main stylesheet (earthy, professional palette)
├── js/
│   └── main.js         # Mobile nav, smooth scroll, contact form handler
└── images/             # Placeholder for images
```

## Design Approach

**Vibe:** Professional, established, trustworthy — not overly modern or trendy.

**Color Palette:**
- Primary: Forest green (#3d5235)
- Accents: Slate blue (#5a7a8a)
- Backgrounds: Warm off-white, light cream
- Text: Dark gray for readability

**Typography:**
- Headings: Crimson Pro (serif — traditional, trustworthy)
- Body: Inter (sans-serif — clean, readable)

**Key Features:**
- Responsive design (mobile-friendly)
- Accessible markup (ARIA labels, semantic HTML)
- Smooth animations on scroll
- Mobile hamburger navigation
- Contact form with validation
- Collapsible FAQ section
- Embedded Google Maps
